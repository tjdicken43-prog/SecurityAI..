LIVE MONITOR

Persistent monitoring control panel

This runs inside the Node process started by node server.js — not in this browser tab. Once you press Start, it keeps capturing and analyzing on your interval even if you close this page, until you press Stop or the server process is shut down.

REQUIRES SETUP

This needs ffmpeg installed on the machine running the server, a real Anthropic API key in .env, and (optionally) SMTP and/or Twilio credentials for alerts to actually send. See README.md. Without those, Start will fail or run without notifications — the dashboard below tells you which.
